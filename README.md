# subwhere-gtfs

Transit timetable data for Subwhere AR — live Stockholm
T-bana trains in AR. This repository hosts the processed GTFS timetable the app
downloads at runtime.

## Attribution

Timetable and transit data in this repository is derived from data provided by
Trafiklab on behalf of SL (Storstockholms Lokaltrafik), licensed under
Creative Commons Attribution 4.0 International (CC BY 4.0).

This data has been modified: it has been processed and reformatted from the
original Trafiklab feed (filtered to T-bana services, reshaped into the app's
CSV/JSON formats, split per station, and regenerated periodically).
